## 怎么用

**一个单元 = 一次摸鱼**。被叫走了就关掉，下次从下一个单元接着读，不需要记进度。

每个单元内部的顺序：

1. **先读英文材料**，不查讲解。读不懂的地方跳过去，别停。
2. **再读讲解**。讲解是按你卡片里的困惑点写的，不是泛泛的单词表。
3. **最后做自测**。答案在 `▸ 答案与解析` 折叠块里，点开才显示——**先在心里答完再点**。

如果一天只有半小时：**做 01、06、09 三个单元**。它们覆盖的考点密度最高。
